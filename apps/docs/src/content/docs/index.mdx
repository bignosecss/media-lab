# medialab

A **framework-agnostic media player**: a framework-free `core` plus React and Vue 3 adapters with independently usable, accessible controller components.

[GitHub](https://github.com/bignosecss/media-lab) · MIT License · React · Vue 3 · TypeScript · Framework-agnostic

## Features

- **Framework-free core** — a single source of truth (`MediaState` / `MediaCommand`) over the media element.
- **React + Vue 3 adapters** — the same component set in both frameworks.
- **Independently usable components** — default styles, a `className` escape hatch, accessible primitives.
- **Playback, captions, fullscreen, speed** — a growing control set at parity.
- **macOS-pink design system** — one `--media-*` token source; override it to re-theme.

## Quick start

```bash
pnpm add @medialab/core @medialab/react react react-dom
```

```tsx
import { MediaProvider, MediaPlayButton, MediaProgress, MediaVolume } from '@medialab/react';

<MediaProvider src="video.mp4">
  <MediaPlayButton />
  <MediaProgress />
  <MediaVolume />
</MediaProvider>
```
