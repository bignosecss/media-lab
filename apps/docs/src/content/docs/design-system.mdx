---
title: Design system
description: The design tokens (a pink drawing on macOS) and how to override them.
---

medialab's visual language is defined by a single set of design tokens in `theme/media.css` (CSS custom properties under the `--color-media-*` namespace), consumed via Tailwind v4 `@theme`. The accent is a **pink that draws on / is inspired by the macOS pink** — it is not the exact macOS system color. Derived shades follow common design practice: darken for hover/press, lighten for emphasis on dark, translucent for subtle backgrounds.

```
--color-media-accent        #f077af    primary accent (played, active, links)
--color-media-accent-strong #ce6697    pressed / hover (darker ~14%)
--color-media-accent-high   #f28dbc    emphasis on dark (lighter ~16%)
--color-media-accent-low    rgb(240 119 175 / .2)  subtle background tint
--color-media-buffer        rgb(240 119 175 / .35)  buffered region (faded pink)
--color-media-track         #94a3b8    neutral track
--color-media-control       rgb(17 17 23 / .72)  control surface
--color-media-control-fg    #ffffff    control foreground
--radius-media              0.7rem     control radius
```

These generate Tailwind utilities (e.g. `bg-media-accent`, `text-media-control-fg`). Consumers import the tokens once and override them to re-theme the player without forking.
