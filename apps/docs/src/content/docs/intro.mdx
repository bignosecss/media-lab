---
title: Intro
description: What medialab is and why it exists.
---

medialab is a **framework-agnostic media player**: a framework-free `core` plus React and Vue 3 adapters that ship **independently usable, accessible controller components**.

- A framework-free `core` owns the media element (the single source of truth) and exposes a typed **state / command** split.
- Each framework is a thin adapter that binds its reactivity to `core` and bundles presentational components.

Built on an AI-Native harness (`AGENTS.md`), inspired by [media-chrome](https://www.media-chrome.org/docs/en/architecture).
